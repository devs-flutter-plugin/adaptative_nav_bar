# adaptative_nav_bar example

The example uses `go_router` with `StatefulShellRoute.indexedStack` and demonstrates:

- compact bottom navigation;
- runtime switching between every built-in bottom style;
- medium navigation rail;
- expanded collapsible sidebar;
- badges;
- destination reselect;
- scroll-driven hide/show behavior.

Resize the window to see presentation changes without changing route configuration.
